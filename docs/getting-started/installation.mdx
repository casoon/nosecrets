```sh

```

<div slot="cargo">

```sh
cargo install nosecrets-cli
```

</div>

<Callout>
  The release installer verifies the downloaded archive against the release SHA-256 manifest.
  Set `NOSECRETS_INSTALL_DIR` to install somewhere other than `/usr/local/bin`.
</Callout>

## Requirements

Prebuilt release binaries are available for Apple Silicon macOS, x64 and arm64 Linux, and x64
Windows. Intel macOS users should install through Cargo. Building from source requires Rust 1.85
or newer. The npm wrapper requires Node.js 16 or newer.
