# nosecrets-report

[![Crates.io](https://img.shields.io/crates/v/nosecrets-report.svg)](https://crates.io/crates/nosecrets-report)

**This crate is merged into [`nosecrets-core`](https://crates.io/crates/nosecrets-core) and no longer developed.** Its code and public types live in `nosecrets-core` since version 0.4.0, together with the other former helper crates; use that crate instead.

Earlier versions of this crate (reporting and output formatting for [nosecrets](https://crates.io/crates/nosecrets-cli)) stay available.

To scan a repository, install the CLI:

```bash
cargo install nosecrets-cli
```
